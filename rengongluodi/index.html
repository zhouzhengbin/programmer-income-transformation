人工落地全流程手册

这份手册把每一步拆到"具体点哪个按钮、写哪句话"的颗粒度。核心原则只有一条：先用最小成本换到真实数据，再决定往哪投入更多。不需要一次全懂，跟着当前阶段做就行。

阶段要做的事预计时间预计花费
01 选题验证确认真的有人为这个问题付费2～3 天0 元
02 制作产品写出一份能真实解决问题的 PDF3～5 天0 元
03 收款账号Payhip/Gumroad + Payoneer 开通半天0 元

07 扩大复制到第二个市场/渠道视情况视情况
08 自动化把已验证的动作逐步交给脚本验证成功后再做视情况
⚠️
提前说清楚：这条路线的目标不是"零思考躺赚"，是把"要不要投入更多钱和时间"这个决定，建立在真实用户行为数据上，而不是建立在猜测或者 AI 自由发挥上。前面几个阶段全是人工操作，正是为了拿到这份"真实数据"。
01

选题与需求验证

目标：在写产品之前，确认"真的有一群具体的人，正在为这个问题苦恼且愿意付费"。

1.1 为什么大多数人第一步就卡死

最常见的失败原因不是"执行力不够"，是选题一开始就选了个和免费内容正面竞争的泛泛话题，比如"怎么用AI赚钱"。这类话题网上有几千篇免费文章，买家没有理由付费。好卖的选题必须具体到"一秒钟就知道是不是在说我"。

对比示例
❌ 泛泛话题："如何用AI提升效率" — 谁都可能是目标用户 = 谁都不是

✅ 具体话题："Etsy 手工饰品卖家：用 AI 在 30 分钟内写完一周的产品文案和客服话术" — 一句话就能筛出真实买家

1.2 选题公式：具体人群 + 具体场景 + 具体结果

把你脑子里的想法套进这个公式，写不出来就说明还不够具体：

公式 【谁】+ 在【什么具体场景下】+ 遇到【什么具体麻烦】，我的产品能让他【做到什么具体结果】

1.3 去哪里找真实需求（不是靠猜，是靠人工蹲点）

Reddit 关键词蹲点打开 reddit.com，在搜索框直接搜你想到的关键词（比如 "translator deadline"），重点看评论区，找那种带情绪的抱怨句子，比如"I always struggle with…"、"Is there any tool for…"。把找到的 3～5 条原话抄下来，这些就是你未来落地页文案的素材库。
同类产品评论区蹲点去 Gumroad / Etsy / Payhip 搜同类关键词，找到已经在卖的类似产品，翻它的评论/问答区，找买家说"如果能再讲讲XX就好了"这种话——这些就是你产品要补的空白，也是你产品能比对手强的地方。
Facebook / 行业垂直论坛搜你目标人群会加入的群组（比如"Freelance Translators Network"），看置顶帖和高赞讨论里反复出现的问题。
Amazon 同主题书籍的 1～3 星评论如果有相关的电子书/纸质书，去它的评论区专门看差评，差评里"这本书没讲到的地方"往往就是市场空白。
阶段一验收清单（全部打勾才能进入阶段二）
02

制作产品

目标：写出一份内容真实、能落地执行的 PDF，不追求排版精美。

2.1 内容大纲结构（照抄这个骨架，填内容就行）

板块内容建议篇幅
开篇说清楚这份指南解决什么问题，读完能做到什么，适合谁不适合谁1 页
核心方法拆成 5～8 个具体步骤，每步包含：做什么 / 为什么这样做 / 常见错误 / 可复制的模板或清单15～20 页
案例或素材包1～2 个具体案例，或一份可以直接套用的模板/清单3～5 页
结尾常见问题 + 下一步行动建议1～2 页

2.2 写作节奏建议

不需要一天写完。按"每天写 1～2 个步骤"的节奏，3～5 天能写完一份 20 页左右的初稿。AI 工具（DeepSeek/ChatGPT等）在这一步的正确用法是帮你把口语化的思路整理成通顺的书面表达，错误用法是让 AI 凭空编一套你自己都讲不清楚原理的步骤——后者会导致买家真的照做出问题，引发大量退款和差评，这是真实的商业风险。

💡
自查标准：写完每一步，问自己"如果有人现在照着做，卡在这一步来问我，我能不能马上答上来"。答不上来说明这步写得不够具体，需要补充。

2.3 排版导出成 PDF（具体操作）

用 Google Docs 写作打开 docs.google.com，新建文档，直接写内容，不用纠结格式，先把内容写完整。
套用简单排版用 Docs 自带的"标题1/标题2"样式分章节，插入目录（菜单栏 插入 → 目录），让文档看起来有清晰结构即可，不需要花哨设计。
导出 PDF菜单栏 文件 → 下载 → PDF文档(.pdf)，就得到了可以直接上架销售的文件。
阶段二验收清单
03

开通收款账号

目标：拥有一个真实能收到陌生人付款、并能提现到国内银行卡的通道。

3.1 在 Payhip 上架产品（具体点击路径）

注册账号访问 payhip.com → 点右上角 "Sign up" → 填邮箱和密码 → 完成邮箱验证
新建商品登录后台 → 左侧菜单 "Products" → 点 "New Product" → 选择 "Digital product"
上传文件与信息上传你的 PDF → 填写商品标题、描述、价格（建议 9～29 美元区间）→ 上传一张封面图（哪怕是简单的文字封面）
绑定收款方式后台 "Settings" → "Payments" → 关联你的 PayPal 或 Stripe 账号（没有的话先去 paypal.com 或 stripe.com 免费注册一个）
发布并拿到链接点击 "Publish"，发布成功后在商品页面右上角能看到 "Share" 按钮，点开复制你的商品购买链接（形如 payhip.com/b/xxxxx），这个链接就是之前落地页模板里 [[CHECKOUT_URL]] 要填的内容

3.2 注册 Payoneer 用于提现

访问 payoneer.com → 点 "Sign Up" → 选择账户类型（个人/自由职业者）→ 用身份证完成实名认证（1～3个工作日审核）→ 认证通过后，在 PayPal/Stripe 后台把提现方式绑定到 Payoneer 账户 → 后续可以从 Payoneer 提现到国内银行卡。

3.3 自测（发布前必做，别跳过）

用你自己的另一个邮箱（或者拜托朋友），完整走一遍"打开购买链接 → 付款 → 收到下载邮件 → 下载文件"的全过程，确认整条链路真的通畅，再对外推广。

04

制作落地页

目标：把产品信息做成一个客户点击链接后能看到、能建立信任、能直接购买的网页。

这一部分我之前已经单独给你做好了一套可以直接用的浅色响应式 H5 模板，以及对应的"每个空格填什么"说明文档。这里不重复贴代码，按下面顺序执行：

填内容打开 落地页模板.html，对照 H5落地页_填空说明 文档，把方括号占位符换成阶段一、二里已经确定的真实内容
填购买链接把阶段三拿到的 Payhip/Gumroad 真实购买链接，填进所有 [[CHECKOUT_URL]] 位置
三处一致性检查价格、退款政策、购买按钮跳转，这三处必须对得上，逐条核对一遍
发布上线用 Netlify Drop（app.netlify.com/drop）把文件拖上去，几分钟内拿到一个真实网址
05

小范围人工投放测试

目标：只花小钱、小范围，验证陌生人是否真的会为此付费。这是整个流程里唯一"见真章"的一步。

5.1 三条路径，选一条能坚持做的（不要三条一起上）

路径具体怎么做成本适合
免费发帖每周在 1～2 个相关 Reddit/Facebook 群组，先分享一段免费干货内容，评论区/简介放链接，不要硬广0 元，需要时间愿意花时间的新手
小额付费广告Meta Ads Manager 后台，每天 5～10 美元预算，只投 1 个国家、1 条素材约 50～100 美元/2周想快速拿到数据的人
中文平台先验证先在小红书/知乎用中文验证模型是否成立，再决定要不要做外语版0 元目标人群本来就有中文用户

5.2 Meta 广告后台具体操作路径（选路径二的话）

创建广告账户访问 business.facebook.com → 创建 Business Manager → 完成企业验证（个人也可以创建，但大额投放可能需要验证）
新建广告系列Ads Manager → "Create" → 选目标 "Sales" 或 "Traffic" → 设置每日预算 5～10 美元
设置受众与素材选择目标国家/年龄/兴趣 → 上传广告图或短视频 + 文案 → 链接填你的落地页网址
人工确认发布提交审核（通常几小时到1天）→ 通过后广告开始投放，每天人工查看一次数据，不建议一开始就用任何自动改预算的工具或脚本
⚠️
广告账户新手常见问题：新账户投放金额过大、素材涉嫌夸大宣传（比如"保证赚钱"类字眼）容易被封号限制。前两周务必保持每天预算低、文案措辞保守。

5.3 两周内容行动日历（免费发帖路径参考）

时间动作
第1～2天在目标论坛/群组潜水，了解发帖规则，避免直接被当广告删帖
第3天发布第一篇"免费干货"帖子（分享部分内容，不直接推销）
第4～7天认真回复评论区问题，观察哪些点大家最感兴趣
第8天发布第二篇，这次可以自然带上落地页链接
第9～14天重复在1～2个新渠道做同样动作，记录每次的点击数据
06

看数据、做判断

目标：用真实数字而不是感觉，决定下一步是继续投入、调整，还是放弃这个选题。
数据情况说明建议动作
曝光多、点击少（点击率 <1%）标题/封面/钩子不吸引人回到落地页，重写标题和 Hero 文案，先别急着加预算
点击多、购买少（转化率 <1%）落地页信任感不够，或价格/内容不匹配预期检查价格是否合理、FAQ是否打消了顾虑、退款政策是否清楚
点击和购买都有，但很少模型基本成立，只是流量规模不够值得进入阶段七，扩大同一渠道的投入
2周内几乎零点击零互动渠道选错了，或选题本身没有需求换一个渠道再测一次；如果两个渠道都是零反馈，认真考虑回到阶段一换选题
💡
不需要追求完美数据才行动。只要出现了"陌生人真实付款"这个信号，哪怕只有1～2单，也说明这个模型是成立的，值得进入下一阶段。
07

验证成功后怎么扩大

目标：把已经跑通的模型，谨慎地复制到更大范围。
先复制渠道，再复制语言同一个语言市场里，多试1～2个新的发帖渠道或小幅提高广告预算，比直接翻译成新语言更划算
翻译新语言市场前，先人工审核用AI辅助翻译落地页和产品内容后，务必找懂当地语言的人（或至少自己借助翻译工具反向检查）通读一遍，确认没有语义偏差
把验证过的定价、退款政策原样复用不要让新市场"重新决定"价格和退款政策，用已经验证过的版本，只翻译语言，减少出错空间
08

自动化分级路线图

等阶段五、六跑出真实成交后再考虑，这里先了解顺序即可。
优先级自动化内容风险
先做已验证文案批量翻译成新语言（人工审核后再用）低——出错顶多是文字别扭，不涉及钱
再做配图/短视频素材批量生成低——出错顶多不好看
最后做，且保留人工确认自动发帖、自动调整广告预算高——直接涉及账号安全和真实花费，建议长期保留"超过一定金额必须人工确认"的红线
⚠️
核心原则：自动化只能重复执行"已经被人工验证过是对的"动作，不能替你做定价、退款政策这类需要你本人承担后果的决定。

新手常见问题

Payhip/Gumroad 提示我的国家不被支持怎么办？+

可以先尝试 Lemon Squeezy 或 Payhip（对个人卖家的地区限制通常较宽松），收款后统一提现到 Payoneer 账户，Payoneer 对国内用户支持较成熟。

广告账户审核被拒/被封怎么办？+

先检查文案是否有夸大宣传字眼，落地页是否信息完整（联系方式、退款政策）。小额、保守的投放记录有助于账户长期健康，新账户不建议一开始就大额投放。

两周测试完全没有任何购买，是不是这个模式不成立？+

不一定。先排查是"没人看到"（曝光/点击数据都很低，说明渠道或标题问题）还是"看到了但不买"（点击不少但转化为零，说明落地页信任感或价格问题），两种情况的下一步动作完全不同，回到阶段六对照表格判断。

我该不该现在就把之前的Python自动化脚本用起来？+

建议先完整走完阶段一到六，拿到至少一次真实成交之后再考虑。脚本能放大的是"已经验证有效"的动作，如果放大的是还没验证过的猜测，只会更快地把问题也放大。
