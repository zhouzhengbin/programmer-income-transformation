先花 2 分钟，把路走正

“短剧 CPS”到底是在做什么？

CPS可以简单理解为：有人通过你已获授权的内容入口进入指定小程序或页面，并完成平台认定的有效付费或广告行为后，合作方按约定规则把一部分推广佣金记到你的账户。它不是“只要发视频就有钱”，更不是先交钱买课就能保证赚钱。

你要做的只有五件事：取得授权、拿到可用素材、做出清楚的短视频、按照授权方式挂载或填写入口、到后台核对数据。页面上有勾选框；每完成一项就勾上，手机下次打开也会记得。

本读本不教“搬运”“破解”“绕审”：没有书面或后台授权的剧，不下载、不剪辑、不发布；不要用镜像、变速、裁剪边角、加水印等方式去躲避重复检测。这样既不能把未经授权的内容变合法，也可能影响账号和收益。所谓“去重”，在这里仅指对已授权素材做真实的二次创作：加入你自己的口播、解说、剧情观点和合法音乐。
1

注册短剧分销平台，拿到授权

目标：不是急着找剧，而是先确认“谁允许你推广、允许在哪儿推广”。

开始前请准备：一部能收短信的手机；本人常用手机号；实名认证所需证件；一张与你实名一致、可收款的银行卡；一个状态正常的抖音或快手账号。请在安静处操作，验证码不要告诉任何人。

先辨认“官方入口”

你可能从同行口中听过“星果”“九州”等名称，也可能拿到一个小程序、网页或邀请链接。不同服务商的名称、下载方式、界面和资格会变化，不要仅凭名字判断可靠。先让邀请人或合作方提供可核验的主体信息、授权/合作说明、官方客服入口和隐私政策；再从应用商店、官方公众号、小程序认证页或对方书面提供的正式入口进入。不要安装陌生人私发的 APK，不要把身份证正反面、短信验证码、银行卡密码发到聊天窗口。

手机上，从“找到入口”到“注册成功”的逐格动作
  1. 打开手机里的 应用商店。安卓手机常见名称是“应用市场”“应用商店”；苹果手机叫 App Store。如果合作方明确说明是微信小程序，就打开微信顶部搜索框，输入对方提供的完整官方名称，不要随便点相似名称。
  2. 在搜索结果里，先看开发者/服务提供者、下载量、隐私说明和用户协议。名称相近、开发者不同、页面要求先转账或只让加私人微信的，先退出。确认后点 获取、安装 或 打开。
  3. 进入后，通常先点 注册、手机号登录 或 新用户。在 请输入手机号 一栏填自己的手机号；点 获取验证码；收到短信后，把六码数字填进 验证码 一栏；阅读协议后再勾选同意。
  4. 如果出现 实名认证、身份核验 或 结算资料，按页面提示填写本人真实姓名和证件信息。姓名、证件号、银行卡开户人必须能相互对应。页面要求填写邀请码时，只填你确认过的合作方邀请码；没有就问客服，不要猜数字。
  5. 注册完成后，先去 我的、设置、账号与安全 看一遍。设置一个不和支付密码相同的登录密码；能开“登录保护”的就打开；把客服电话或在线客服入口截屏保存。

在平台里申请“推广授权”

不同后台可能把入口叫作 剧库、选剧中心、推广中心、任务大厅 或 短剧授权。你不需要把这些词背下来：进入后，找带有“剧”“推广”“授权”“素材”“任务”其中任一词的菜单。找不到时，点右上角放大镜搜索“授权”，或直接问平台官方客服“我是新手，想申请某剧在抖音/快手的推广授权，入口在哪里？”

选择一部剧并形成“授权留痕”
  1. 在 剧库/选剧中心 的筛选处，优先选择页面明确标注 可推广、有素材、抖音可用 或 快手可用 的剧。不要只看“佣金高”；先看授权渠道、有效期、允许的账号数、素材使用规则和结算规则。
  2. 点进剧目详情页，先找 推广规则、授权说明、推广协议 或 素材规范。把包含剧名、渠道、授权时间、授权编号（如有）的页面完整截屏。截图不要裁掉顶部时间和底部信息。
  3. 确认后点 申请授权、立即推广 或 领取任务。如果弹出选择平台，就只勾你准备发布的平台，例如“抖音”或“快手”；如果要求填账号昵称、主页链接或账号 ID，按自己账号资料页复制后粘贴，不能填别人的号。
  4. 申请成功后，页面通常会出现 推广链接、推广口令、小程序名称、绑定账号 或 领取素材。每项都点一次确认。看到 复制 时，点击复制；随后立即打开手机备忘录，新建一条，标题写 剧名＋日期＋发布平台，长按空白处点 粘贴。
  5. 最后回到剧目页，确认状态不是“审核中/已失效/不可推广”，而是类似 已授权、推广中。若仍在审核中，先不要发布，等状态变为已通过或问官方客服。
授权链接/口令核对小表：复制后先记下来，不要只靠剪贴板
你要核对什么正常状态发现问题时怎么做
剧目名称与素材文件、后台详情页一致名字不一致，停止使用，问客服。
推广渠道明确显示抖音、快手或对应渠道未写渠道，不默认“全平台都能发”。
链接/口令复制后粘贴进备忘录，内容完整复制为空或乱码，回后台重新复制。
授权状态/日期已授权且在有效期内审核中、过期、下架，都不发布。
账号绑定是你自己的账号信息绑错账号，先联系官方客服改正。
2

找可用素材，在手机里下载并整理

目标：只使用“这部剧、这个渠道、当前授权”允许使用的素材。

新手常犯的错误，是去别人的抖音、快手或网盘里“扒视频”。那不是找素材，而是在把版权、账号和收益风险一起搬回自己手机。正确做法是：从你已经申请成功的剧目详情页里领取素材，或从授权方明确给出的素材包链接下载。部分服务商会写“素材中心”“剧集片段”“推广包”“混剪素材”或“领取素材”；按钮词不同，原则一样。

先用“是否值得试”筛选，不盲目追爆款

新手选第一部剧的四个检查格
检查格你在页面上看什么新手怎么判断
授权完整渠道、期限、素材规范、可推广状态这一格不清楚，其他再好也先不选。
素材够用是否有多条不同剧情片段、封面、文案建议先选至少有 6—10 条可剪片段的剧，方便连续测试。
故事钩子前几秒是否有冲突、误会、反转、重要决定把“发生了什么”用一句大白话讲得清，才适合新手。
你看得懂人物关系、关键剧情、观众可能会问什么你自己都看不懂，就很难写出自然的字幕和说明。
“爆款”不等于“看别人发得多”。对新手来说，更稳的标准是：你有正规授权、能找到剧情冲突、素材清楚、能连续做几条不同角度的内容。平台会根据账号、内容质量、观众反馈和规则综合分发，任何人都不能承诺播放或佣金。

手机下载授权素材：从按钮到相册

以“素材中心/领取素材”为例的手机操作
  1. 回到刚才那部已授权的剧详情页。寻找 素材、去领素材、下载素材 或 素材中心。进入后，先看顶部是否仍显示同一个剧名。
  2. 如果列表里有“片段 01、片段 02”或剧情标题，先点播放预览。挑一个前 1—3 秒就有事情发生的片段，例如人物冲突、身份被揭开、做出选择；不要从长时间铺垫开始。
  3. 确认是授权素材后，点右侧 下载、保存到相册 或 保存视频。第一次使用时，系统可能弹出“是否允许访问照片和视频”；选择允许“所有照片”或“选中的照片”，否则剪映看不到视频。
  4. 下载时先连稳定 Wi-Fi，等进度条完全结束。页面若提示“已保存至相册”，不要立即关闭；打开手机 照片/相册，进入 最近项目 或 视频，实际播放 2 秒确认文件能打开、有声音、画面不花。
  5. 为了不找乱，在相册新建相簿（苹果可点“相簿”→“＋”；部分安卓在“相册”→“新建相册”），命名为 短剧素材－剧名－日期。把这一部剧的片段都放进去。不同剧不要混在一个文件夹。

下载后，先做一张“剧情小抄”

打开手机备忘录，写下这四行即可，不必写得漂亮：谁、发生了什么冲突、观众最想知道什么、下一集/完整内容在哪里看。例如：“女主是谁？她突然被赶出家门；观众会想知道她怎么翻盘；已授权小程序内可继续看。”这张小抄是你剪字幕、写标题时的底稿，能避免剧情说错。

不要把后台下载的推广链接直接公开贴在不允许外链的地方。你要使用的入口方式，必须按授权后台和发布平台给出的方式执行；有的平台是小程序挂载，有的是指定口令，有的是后台绑定。先把“入口究竟是什么”搞清楚，再剪片。
3

手机版剪映：裁剪、讲清剧情、做合规二创

目标：让观众一眼看懂冲突，而不是把一整段剧原样搬过去。

先说清“去重”：不要把“去重”理解成镜像、抽帧、改速度、遮水印来规避检测。本教程不提供这类做法。对授权素材，正确的做法是加入实质性的自有表达：你的口播解释、剧情评论、清晰字幕、自己的开场和收束。即使拿到素材，也仍要遵守授权方的素材规则与平台原创规则。

第一次打开剪映，做一个竖屏工程

从“新建项目”到“视频比例正确”
  1. 从应用商店安装 剪映，打开后若提示登录，可按自己的习惯登录；如果只是本地剪辑，先不要随意把授权素材上传到公开模板。回到首页，点中间的 开始创作 或 ＋ 开始创作。
  2. 相册弹出后，进入你刚建的 短剧素材－剧名－日期 相簿。单击选中一条片段，选中后会出现序号；点右下角 添加。
  3. 进入编辑页，先看预览画面。若不是竖屏，点底部工具栏的 比例，选择 9:16。这就是抖音、快手最常用的手机竖屏比例。画面两侧有空白时，点视频轨道后用双指轻轻放大，保持人物脸和关键动作在画面内；不要把字幕区裁掉。
  4. 先不要急着加音乐。用手指按住底部视频轨道的左边或右边白色边框，向内拖动，就是裁掉开头或结尾。先把“还没发生事情的空白镜头”和“片尾无关画面”删掉，保留最有冲突的 15—45 秒。具体时长以后台素材规范和平台页面为准。
  5. 如果中间有一段沉默或剧情不重要，把播放针拉到那一处，点 分割，再点中间那段视频，点 删除。每做一次删除都从头看一遍，确保人物说话没有被切成半句话。

给短片加“看得懂”的文字，不堆满屏

大白话字幕的安全做法
  1. 把播放针放到视频开头 0—1 秒。点底部 文字 → 新建文本。第一句只写“这段发生了什么”，例如 她刚回家，就被通知：你不是亲生的。 不要写夸张承诺、虚假收益、低俗暗示或攻击性词语。
  2. 选中文字，点 字体 选笔画清楚的常规黑体；点 样式，使用白字＋深色描边/深色半透明底。字号放到你自己在一臂距离能看清。文字放在画面中下部，但不要贴最底边，避免被平台按钮遮住。
  3. 把播放针移到剧情转折处，再点 新建文本，写第二句，例如 更意外的是，父亲把所有家产都给了她。。一屏最好只讲一件事。每句停留时间与人物说话或动作同步，拖动文字条两端可拉长或缩短。
  4. 如果需要口播，点 音频 → 录音，按住录音按钮，用自己的话补充一句，例如“前 30 秒把身份反转交代清楚，后面去授权入口继续看。”先听回放；结巴明显就重新录，不要强行使用刺耳或难懂的机器声。
  5. 若确实使用背景音乐，只从剪映明确可用的曲库或你自己有权使用的音乐中选，音量降到能听清人声的程度。不要把其他短视频里的热门音乐直接搬来，也不要用音乐遮住剧中关键对白。
发布前，给自己播放一次的“60 秒检查法”
时间点你要看什么不合格就怎么改
第 0—3 秒是否有明确人物、冲突或问题把最有事发生的镜头提前，不要空镜头开场。
第 3—15 秒字幕能否一遍看懂，人物脸是否被裁掉减少文字、调大字号、重新移动字幕位置。
中间部分声音是否清楚；是否有无授权水印、无关账号信息回到授权方确认；有疑问先不用这条。
最后 2—4 秒是否自然说明“到哪里继续看”，没有强迫诱导改成中性提示，例如“已按授权方式挂载，点组件了解剧情”。
整条视频是否是自己能解释清楚的内容，且符合已获授权范围看不懂/说不清/范围不明，一律先不导出。

导出到相册，再做最终核对

点击右上角 导出。如需选择清晰度，优先选你手机能正常导出、画面清楚且文件不过大的选项；不要反复压缩导致模糊。等到出现“已保存到相册”后，退出剪映，打开相册从头播放一次。确认没有剪映草稿提示、没有未授权素材、字幕没被边缘裁掉，才进入下一步发布。

4

在抖音/快手发布，并按授权方式挂载

目标：先看账号是否有资格，再在发布页做“视频—剧目—入口”一致的核对。

最重要的事实：不是每个账号、每个剧、每个服务商都会出现“挂载小程序”按钮。抖音公开的短剧行业说明中，自然流量原生锚点需要小程序取得对应能力，且账号需满足相应条件；合作计划、授权绑定和版本也会影响入口。[来源 1] 所以：没看到按钮，不要用假链接、虚假标签或别人账号替代。

②视频做完
③发布页选择剧目/组件
④发布后点开自查
⑤后台看归因

抖音发布：先上传，再找“添加/挂载”入口

抖音手机端的常见操作路径（页面词可能因版本更新不同）
  1. 打开抖音，确认登录的是你在授权后台登记的账号。点底部中间的 ＋，再点右下角或相册图标 相册；选中刚才导出的短片，点 下一步。不要使用尚未授权的他人视频。
  2. 进入发布编辑页后，先看预览是否竖屏、字幕是否完整。填写标题/描述时，用一句“剧情＋悬念”的大白话即可，例如 她被赶出家门那天，才知道自己才是继承人。 内容一定要与视频真实剧情一致；不写“点了就赚钱”“保证免费看全集”等无法证实的话。
  3. 寻找发布页中的 添加小程序、添加组件、小程序、添加链接 或授权后台明确说明的挂载入口。不同版本按钮位置会变化，可能在“更多功能/高级设置”里。如果后台要求先绑定账号，先回授权后台完成绑定再回来。
  4. 进入剧目/小程序选择页后，搜索授权后台给出的准确小程序名称或剧名。能搜索到时，点开详情核对剧名、封面和授权平台；确认无误再点 添加 或 完成。搜不到时，不要选择名称相似的别的剧，截图后问官方客服。
  5. 如页面给了 原创声明，只有在你的内容确实符合平台的原创定义和授权条件时才按规则选择。最后重新检查“视频内容”和“挂载剧目”是不是同一部，确认后点 发布。

快手发布：以“实际可见的挂载能力”为准

快手手机端的常见操作路径（不要把别人的后台路径照搬）
  1. 打开快手，确认账号状态正常且与授权后台登记的信息一致。点底部中央 ＋，选择 相册 或 上传视频，从自己的“短剧素材”相簿选择已导出的作品。
  2. 在编辑或发布页填写简洁标题。例如 她把亲子鉴定撕碎后，全家都慌了。 标题描述剧情，不能以收益、夸大效果、擦边内容吸引点击。封面选择人物表情或冲突画面清楚的一帧，封面文字不要贴边。
  3. 寻找 小程序、关联小程序、挂载、更多服务 或授权方说明的具体入口。快手公开资料说明，短剧小程序的挂载能力需要能力接入与配置，入口与账号资格会随后台权限而变化。[来源 2]
  4. 若进入选择页，搜索授权后台给出的准确剧目/小程序；核对剧名后添加。若只看到与自己视频无关的小程序，或根本没有入口，先不发布或按合作方明确给出的无挂载发布方案执行。切勿用不相关组件凑数。
  5. 最后点 发布。发布完成后不要马上删原稿或改成别的剧。先进入自己的主页，点开刚发的视频，确认组件位置、剧名和跳转对象正确。
“发布成功”不等于“挂载成功”。发布后请用自己的账号或请家人手机，在不登录后台的情况下打开视频：组件是否显示？点进去是否是同一部剧？若跳转错误，立刻保留截图并联系授权方官方客服；不要反复删除重发来碰运气。

查看收益、理解结算、申请提现

目标：分清“播放”“预估”“已结算”“可提现”，不被数字带着着急。

不同平台的佣金触发条件、退款扣回、结算周期、最低提现额和税务处理并不相同。你看到的“播放量”不是佣金；“预估收益”也不等于到账金额。以合作后台的订单规则和结算记录为准。公开视频/组件规则还会更新，因此不要根据别人截图判断自己一定能拿到同样的金额。

收益页常见四种词：先分清再高兴
页面词大白话意思现在该做什么
播放/曝光/点击有人看到了、点到了，不代表已经产生可结算佣金。记录这条视频，继续看内容是否清楚。
预估收益/预计佣金系统按当前数据暂时计算，后面可能因退款、审核、延迟而变化。先不当作可花的钱，等待结算状态。
已结算/可提现后台确认符合规则、可按提现规则申请的钱。核对姓名和银行卡，按提现页操作。
冻结/审核中/异常有资料、订单或合规问题待核对。截图保存，找官方客服；不要交“解冻费”。

每天 3 分钟看数据，先找问题不急着加量

通用后台查看路径
  1. 打开授权平台或合作后台，点底部 我的，寻找 数据、推广数据、订单、收益 或 钱包。
  2. 在日期筛选处，先选 今天，再选 近 7 天。只看今天容易误判；短剧订单、归因和结算可能有延迟。打开你发布的那部剧，核对是否有视频/渠道维度的数据。
  3. 如果一个视频有播放却没有点击，先检查：开头是否慢、字幕是否难懂、挂载入口是否出现。如果有点击但无有效订单，不能自行判断是“平台不给钱”；先看后台对“有效”的定义、结算延迟和退款规则。
  4. 新手建议每次只改一个地方。例如下一条只把开头冲突提前，不要同时换剧、换标题、换音乐、换账号；这样你才知道什么变化有用。不要为了追数据频繁删视频、买不明流量或刷量。

提现前的最后核对

从“可提现”到“银行卡到账”的稳妥步骤
  1. 在 我的 → 钱包/收益 页面，先找 可提现 金额。不要把“累计收益”“预估收益”当作可提金额。点击 提现规则 或问号图标，读清最低金额、手续费（如有）、到账时间和限额。
  2. 第一次提现通常要点 添加银行卡 或 收款账户。在 开户人姓名 填本人实名；在 银行卡号 逐位核对；选择正确的开户行或按页面自动识别。不要填写他人的卡、不要填写信用卡密码。
  3. 返回收益页，点 提现。在 提现金额 处先填一个自己愿意测试的小金额，前提是符合最低提现额；不要因为陌生人催促而把钱转到“验证账户”。输入平台要求的支付/安全验证后再提交。
  4. 提交后截图保存 提现记录，要截到金额、时间、状态和订单号。页面显示“处理中”时，按页面给出的工作日等待；不要连续反复提交。若显示失败，先看错误提示、核对银行卡，再联系官方客服。
  5. 银行卡到账后，回到后台把提现记录和银行入账记录对照。若超过后台承诺的处理时间仍未到账，只通过官方应用内客服、官网电话或已核验的工单咨询，并提供订单号；不要相信私信里自称“提现专员”的人。

最容易卡住的 8 个地方

遇到一个问题，只处理一个问题；不要连续点、不要病急乱投医。

我注册后没有看到“推广/授权”按钮，怎么办？
先检查账号是否已完成实名认证、是否在正确的“创作者/推广”身份入口、是否需要审核。截图当前页面和账号 ID，通过官方客服问“新手申请短剧推广授权的入口、审核条件和当前状态是什么”。不要通过私下转账购买所谓“开通权限”。
我拿到链接了，但抖音/快手发布页没有“小程序”按钮，怎么办？
先回授权后台看是否要求绑定账号、是否有指定发布方式，再看平台创作中心的账号状态和可用能力。该入口受账号资格、合作绑定和产品版本影响。没有入口时不要用不相关组件替代，也不要把不允许的外链硬塞进标题。
视频被提示审核中或不给推荐，是不是要马上删掉？
先看具体通知。审核中不等于违规；如果有明确违规提示，按提示修改或申诉。不要靠反复删除重发来试错，更不能把未经授权素材换个方式继续发。保留原始授权截图和发布截图，方便与官方客服沟通。
为什么有播放量，后台收益却是 0？
播放并不等于有效付费或有效广告行为；数据也可能延迟。先确认视频组件是否正确、授权是否有效、后台统计周期和有效订单规则。不要相信“帮你刷几单就能激活收益”的说法，这类行为可能导致封号或结算异常。
有人说交钱就能给我“一级授权”或保证每天佣金，可信吗？
任何保证收益、催你立刻转账、要求私发证件/验证码的说法，都应该提高警惕。授权范围、结算方式和费用必须有可核验的官方后台/书面规则。你有权先问清楚，再决定是否合作。
我不会写标题，能不能照抄别人？
不要整句照抄，也不要用他人的水印和画面。最简单的标题公式是“人物＋一件冲突＋一个问题”：例如“她刚领证，丈夫却说新娘不是她”。必须真实对应视频剧情，别夸大、别低俗、别虚假承诺。
我什么时候应该扩大数量？
先连续完成一个小周期：合法授权、稳定发布、组件核对、后台数据可追溯。只有当你能清楚解释哪些剧、哪些开头、哪些字幕更容易带来合规的有效行为时，再逐步增加。不要借钱投流、不要把生活费押在佣金上。
客服让我提供哪些信息才合适？
可以提供：平台内账号 ID、剧名、授权编号（如有）、截图、发生时间、订单号。不要提供：短信验证码、登录密码、银行卡密码、屏幕共享控制权。官方客服也不应要求你把钱转到个人账户“解冻”。
