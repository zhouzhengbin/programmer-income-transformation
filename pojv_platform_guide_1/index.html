03 — 平台定位与核心理念

平台名称：「破局」

不是招聘平台，不是知识付费，不是社交网络。破局是一个"个人处境导航系统"——AI驱动的、从诊断到行动的全链路帮扶平台。免费为主，合规运营，让最困难的人第一个受益。

🧭
核心定义：处境导航系统

用户告诉系统"我是谁、我在哪、我有什么"，AI给出"你能做什么、先做哪一步、预期能达到什么结果"的具体可执行方案——不是泛泛而谈的建议，是今天就能开始的行动。

🔍
差异化护城河：政府资源寻宝

全国各省市就业补贴、职业培训补贴、创业扶持、低保申请、公益法律援助……每年数百亿资金因信息不对称被"沉睡"。我们帮用户找到属于自己的那一份，这是所有平台都没有在做的核心功能。

🛡️
机会真实性验证

市面上骗局泛滥，普通人被骗、被坑的经历让他们对任何平台都有防御性。破局建立"机会真实性评分"系统，对所有机会/任务进行风险标注，从底层建立信任。

🤝
同境遇互助圈

把相似处境的人连接在一起——同城失业的人、同龄转型的人、同行业被裁的人……不是鸡汤，而是真实的"我做了什么、结果如何"的经验分享，形成真实可信的同伴网络。

平台六大原则
  • 原则一：免费优先核心功能永久免费。最困难的人往往也是最穷的，付费门槛是对他们的二次打击。收入来自愿意付费的增值服务，而非对最需要帮助的人收费。
  • 原则二：行动导向所有内容、所有建议必须能转化为"今天就能做的第一步"。杜绝空洞的励志内容，只给可执行的路径。
  • 原则三：真实第一所有机会、收入预期必须标注真实数据，不允许夸大宣传。平台主动打击虚假信息，不做"月入过万"的噱头。
  • 原则四：本地化政府资源、兼职机会、互助圈子必须精准到用户所在城市/区域，全国性的内容对具体的人帮助有限。
  • 原则五：尊重用户不收割焦虑，不贩卖恐惧，不鼓励"躺平"。语言平实、务实，把用户当成有尊严的成年人，而非待收割的韭菜。
  • 原则六：合规优先所有功能在上线前完成法律合规审查。不触碰就业歧视、求职诈骗、非法集资等法律红线。信息安全、用户隐私保护符合个人信息保护法要求。

06 — 八大核心功能模块详细设计

平台八大模块完整规划

以下八个模块是破局平台的核心，每个模块都有明确的用户价值主张、具体功能和数据设计。按优先级排序，建议MVP阶段先完成前三个。

M-01
🧭 AI处境诊断引擎
MVP核心 · 优先级最高

用户价值：5分钟内告诉你"基于你的真实情况，现在能做什么"——不是通用建议，是专属于你的行动方案。这是整个平台的入口和灵魂。

核心交互流程（对话式，非表单式）：

  • 步骤1：破冰提问用聊天气泡形式，语气亲切。"你好，告诉我你现在的处境——不用写完整，随便说都行"。消除用户心理防御。
  • 步骤2：结构化追问AI自动识别用户信息中的缺失项（年龄/城市/学历/技能/可投入时间/期望月收入），用追问的方式补全，而不是让用户填20个表单项。
  • 步骤3：生成处境画像系统将用户信息结构化为"处境卡片"，展示给用户确认：你的优势、你的限制、你所在城市的就业环境。
  • 步骤4：输出三条路径给出3条当前最可行的路径，每条路径包含：路径名称、预期月收入范围（真实数据）、上手门槛（1-5星）、今天就能做的第一步、成功概率估算。
  • 步骤5：关联资源推送根据用户城市和处境，推送匹配的政府补贴、免费培训机会、附近互助圈。

技术实现关键点：

  • 多轮对话状态管理后端维护 session context，每轮对话的用户信息增量更新到结构化 JSON 对象，而非每次重传完整上下文（节省 token）。
  • 输出结构化 JSONPrompt 强制要求大模型以 JSON 格式输出，前端解析渲染，而不是显示纯文本（更可控、更易维护）。
  • 结果持久化诊断结果存入数据库，用户可以随时查看历史诊断，并在处境变化时重新诊断对比。
  • A/B Prompt 测试维护两套以上 Prompt 模板，通过数据监控选出转化率更高的版本。
M-02
🗺️ 政府资源导航仪
MVP核心 · 最独特壁垒

用户价值：全国最全的"普通人可申请的政府资源"数据库，精确到城市，结合用户身份智能匹配，点击即可看到"你能申请哪些"以及"怎么申请"。这是现有任何平台都没有系统性做过的功能。

数据库覆盖范围（需持续运营更新）：

  • 就业补贴类灵活就业人员社保补贴、应届毕业生就业补贴、见习基地补贴、离校未就业高校毕业生求职补贴（部分地区500-2000元）
  • 职业培训类免费职业技能培训（各地人社局主办）、"技能中国行动"相关培训、补贴性培训（完成后可报销培训费）
  • 创业扶持类小额担保贷款（最高可达20-50万）、创业孵化器免租金政策、大学生创业补贴（各省差异大）
  • 社会保障类失业保险金申领条件和流程、最低生活保障申请、临时救助金申请
  • 法律援助类免费法律援助机构（劳动纠纷、欠薪追讨）、12333劳动投诉热线使用指南
  • 其他公益性岗位申请、农村回乡创业政策、残疾人就业扶持政策

交互设计核心：

  • 三步筛选选城市（精确到区/县） → 选身份（应届生/失业/农民工/返乡创业等） → 展示匹配结果列表
  • 状态标记每项资源标注"申请难度（简单/中等/复杂）""时效性（长期/截止日期）""核实时间（最近核实日期）"
  • "我要申请"按钮给出具体申请地址（线上/线下）、所需材料清单、注意事项；复杂的申请提供AI辅助填写功能
  • 用户反馈机制申请成功的用户可以反馈"实际到账金额"，让数据更真实可信

数据维护策略：招募志愿者（失业/在职社工/公益律师）参与数据核实，建立定期更新机制；利用爬虫监控官方人社局网站政策更新，AI自动解析并入库审核。

M-03
💡 技能变现路径地图
MVP核心

用户价值：不是课程推销，而是"从你现在拥有的，到你能赚到的"的具体地图。告诉用户：每条变现路径的真实收入范围、需要多长时间上手、哪里可以接单、可能遇到的坑。

路径库构建（约200+条经过验证的路径）：

M-04
🛡️ 机会真实性防骗检测
信任基础

用户价值：用户粘贴任何看到的"赚钱机会"描述，AI+规则引擎给出真实性评分，标出红旗警告，帮助用户避开骗局。这是建立平台信任的底层基础，没有这个，用户不会信任其他任何推荐。

检测维度：

  • 承诺收益核验若宣称"月入X万"，与路径库中该类别的真实收入范围比对，偏差超过300%自动标注"不实宣传"
  • 先收费模式识别凡是要求先缴纳"押金/培训费/入门费/工具费"才能开始工作的，90%以上是骗局，自动红旗标记
  • 关键词语义识别使用NLP识别常见骗局话术："保本保收益""内部项目""限时名额""平台认证讲师"等
  • 来源可信度评估对比"是否有真实可查的公司主体""是否有公开投诉记录""联系方式是否为个人微信"等
  • 用户举报积累被多名用户举报过的信息进入黑名单库，持续更新

输出格式：可信度评分（0-100）+ 颜色等级（绿/黄/红）+ 具体风险点说明 + 如何核实真实性的指引。用语言简单、不居高临下。

M-05
🤝 同境遇互助圈
社区粘性

用户价值：不是论坛，不是微信群，而是"根据你的处境，把你和最相似的人连在一起"的精准社群。1000个同类处境的人互帮互助，比100万人的广场更有价值。

圈子分类逻辑：

  • 按处境标签自动分配"应届互联网转行圈" "武汉失业互助" "全职宝妈副业探索" "40+中年转型" "返乡农民工" "小微商户自救"——用户完成诊断后自动被推荐匹配的2-3个圈子
  • 行动日志机制鼓励用户发布"今天做了什么""结果如何"的短日志，不是发表文章，而是打卡式的行动记录，低门槛高互动
  • 经验帖子结构化分享帖强制包含：处境背景 / 做了什么尝试 / 真实结果（不夸大）/ 建议和坑。消灭虚假成功学内容。
  • 圆桌互助活动每周组织"同城见面交流"或"线上共读行动"，圈主由活跃成员自然产生，平台给予流量激励
  • 匿名模式涉及个人困境的帖子支持匿名发布，保护用户隐私和尊严

内容治理：AI自动过滤广告、骗局、情绪化攻击内容；人工志愿者版主审核；屡次违规者限制发言。圈子健康度作为独立指标持续监控。

M-06
📋 本地微任务市场
本地化特色

用户价值：不是美团外卖、不是BOSS直聘，而是"个人发布、个人接单"的超本地化、低门槛微任务市场。帮人搬家、代排队、帮老人跑腿、临时文字整理……这些需求真实存在，但没有专门平台服务。

任务类型设计：

  • 线下跑腿类代购物/排队/送餐/接送（非专业司机，邻里互助性质）；收费：20-100元/次
  • 线上轻技能类帮人搜索资料、整理Excel表格、做简单PPT、临时翻译校对；收费：30-200元/单
  • 线下手工类家务清洁、简单维修（水管/门锁等）、搬运；平台不介入，双方自行协商，平台仅做信用背书
  • 经验分享类当地熟悉某行业的人提供1小时咨询服务（如：在工厂干了15年的师傅提供转型咨询）

关键设计：

  • 身份核验接单方必须完成手机号+身份证核验（不存储身份证图片，仅调用三方核验API验证真实性），保障双方安全
  • 信用体系完成每笔任务后互相评分，信用分公开展示；初始信用分基于学历/年龄/其他平台资料评估
  • 平台担保支付（可选）发布方可选择平台担保支付（任务完成确认后再释放），平台收取5%服务费；也可以自行私下交易（不收费）
  • 合规边界明确告知用户：平台仅为信息匹配，不承担雇佣关系责任；所有任务不涉及"人身依附""持续工作关系"
M-07
📄 AI简历与材料优化
高频刚需

用户价值：上传简历或口述经历，AI帮助重写、优化、针对特定岗位调整，输出可直接使用的Word/PDF文件。同时提供政府补贴申请材料、创业申请书等非职场文件的AI辅助写作。

  • 简历分析诊断自动识别简历中的弱点（空白期、描述过泛、缺少量化数据），给出具体修改建议
  • 针对岗位改写用户粘贴目标岗位JD，AI自动调整简历关键词和侧重点，提升ATS通过率
  • 空白期处理策略专门针对宝妈/中年转型/失业期长的用户，给出如何诚实且正面地处理空白期的具体写法
  • 政府申请材料助手帮用户填写"创业补贴申请书""就业困难人员认定申请""低保申请陈述"等官方材料，降低行政门槛
  • 求职信/自我介绍生成根据岗位和个人背景，生成3个版本（不同语气风格），用户选择修改
M-08
🧠 心理稳压与情绪支持
用户留存关键

用户价值：失业的人焦虑、迷茫、自我怀疑是普遍现象。如果平台只提供工具，不提供情绪支持，用户会在最需要帮助的时候放弃。这个模块是无声的底层托举。

  • 情绪自测小工具简短5题，识别用户当前情绪状态（焦虑/平稳/抑郁倾向），决定推送内容的基调。不做心理诊断，不替代专业治疗。
  • 每日小行动打卡"今天的小赢"打卡系统——每天完成1个小任务（比如：整理简历、申请了一个补贴、发了一条接单信息）即可打卡，积累成就感，对抗无力感
  • 故事库：真实的突破故事收集真实用户的"从X到Y"故事（严格核实，不虚构），分类展示。不是成功学，而是"他们能，你也可能能"的真实参考。
  • 专业资源跳转当AI检测到用户描述出现极度低落/绝望等信号时，温和地推荐专业心理援助热线（北京心理危机研究与干预中心：010-82951332；全国心理援助热线：400-161-9995），不强制，不夸大。
  • 重要声明平台不提供心理咨询服务，不作出任何医疗相关承诺。所有情绪支持功能均标注"仅供参考，如需帮助请联系专业机构"。
07 — AI能力集成方案

AI如何赋能每个模块

你没有资源训练自己的模型，但你可以站在巨人肩膀上。国产大模型API成本持续下降，合理设计可以用极低成本撬动强大AI能力。

⚡
核心原则：用最少的钱，做最大的事
优先使用国产大模型（DeepSeek、通义千问、文心一言），一方面更符合中国用户语言习惯，另一方面合规性更强，且成本更低。GLM-4.6 成本约0.3美元/百万token，DeepSeek V3约0.5美元/百万token，远低于GPT-4o。

AI中台架构设计

🔄
多模型路由策略

不同场景用不同模型：简单分类任务（DeepSeek-R1 小模型）、复杂诊断（DeepSeek V3 / 通义Max）、内容安全过滤（微调专用模型）。根据响应质量和成本自动选择最优路由。

💾
语义缓存（Semantic Cache）

将历史对话的语义向量存入向量数据库（pgvector），新请求先检索语义相近的历史回答，相似度阈值内直接复用，不重复调用大模型。预估可节省30-50%的API成本。

⚙️
Prompt工程体系

建立Prompt版本管理系统，每个功能模块维护独立的System Prompt、示例Few-shot和输出格式规范。A/B测试框架持续优化，记录每个版本的质量评分。

🛡️
安全过滤层

所有AI输入输出经过双重过滤：输入端屏蔽违法内容/PII敏感信息；输出端检测幻觉、错误建议、有害内容。中国合规要求（网信办规定）必须满足。

📊
效果监控Dashboard

监控每日AI调用量、平均延迟、成本消耗、用户满意度评分（拇指评价）、幻觉率（人工抽检+自动评估）。建立告警机制，成本超预算时自动限流。

🎯
RAG知识库检索

将政府政策文件、路径库内容、反骗案例库向量化存储，诊断时结合RAG检索增强，让AI输出基于真实数据而非凭空生成，大幅提升准确性。

10 — 合规体系与风控设计

合规优先：法律红线与风控

在中国运营互联网平台，合规是生死线。以下是破局平台必须遵守的核心法规要求和对应的技术/运营措施。

⚠️
必须取得的资质证照（上线前必须完成）：
① ICP备案（工信部）—— 域名和服务器备案，必须 ② 网络安全等级保护三级备案 ③ 如涉及就业信息发布需取得《人力资源服务许可证》④ 如有付款功能需取得第三方支付接入资质（微信/支付宝商户即可）⑤ 如发布医疗/心理相关内容，需注意严格限制，不得宣称诊断治疗功能
📋
个人信息保护法（PIPL）

最小化收集原则：只收集必要数据；明确告知用户数据用途；提供数据下载和删除功能；AI调用时对用户数据脱敏；数据不出境。需聘请法律顾问审核隐私政策。

🤖
生成式AI服务管理办法

国内大模型API服务商已负责模型合规性，但平台需做好：输入内容过滤（不允许用AI生成违法内容）、输出内容审查、明确标注"以下内容由AI生成"、不允许AI模拟真实人物。

💼
就业信息发布规定

所有招聘/任务信息禁止包含性别歧视、年龄歧视；不得收取求职者费用（任务担保金需明确界定为非求职费用）；不得发布违法岗位（黑中介、非法传销等）；严格内容审核。

🏦
支付与资金安全

担保支付使用微信支付/支付宝官方API，平台不自行存储资金（不做支付牌照）；提现需实名认证；超过一定金额（5万以上）触发风控上报；严格防止洗钱和赌博变种。

👦
未成年人保护

注册强制实名核验年龄；不允许16岁以下用户发布任务或接单；对青少年模式下的内容额外过滤；心理支持内容不对18岁以下用户展示潜在有害内容。

📢
互联网信息服务管理

用户发布的内容须经过AI+人工双重审核；建立举报机制（被举报内容72小时内处理）；保存用户行为日志（法定要求）；不得传播谣言、违法信息；政治敏感词汇严格过滤。

11 — 冷启动策略

从0到第一批用户的方法

没有资源、没有团队，如何让第一批用户发现并留下来？破局的冷启动不依赖投放，依赖精准社群渗透和真实价值。

P1
第一阶段 · 0-4周
核心用户种子：100个真实故事
不要急着上线，先找100个真实处于困境的人（豆瓣失业小组、知乎相关话题下评论区、闲鱼卖家群体），手动帮他们用你的"诊断逻辑"分析处境，给出建议。记录他们的反馈，迭代产品逻辑。这100人将成为最忠诚的早期用户和口碑传播者。
豆瓣失业互助小组主动提供帮助 知乎相关问题下真诚回答 手动MVP验证诊断逻辑
P2
第二阶段 · 1-2个月
政府资源数据库：最强差异化启动
先上线"政府资源导航"这一个功能，发布到微博/小红书/知乎，标题就是"你可能不知道的失业补贴：各省完整清单"。这类内容天然具备传播力（真实有用、稀缺），无需投放即可获取精准流量。收集用户反馈，快速补充和纠错数据。
发布各省补贴数据整理内容 在HR/法律/公益类账号下合作传播 目标：小程序2000次体验
P3
第三阶段 · 2-3个月
AI诊断上线：核心拉新工具
上线AI诊断引擎，主打"5分钟告诉你现在能做什么"。在失业/求职相关话题下推广"让AI帮你看看你的处境"活动。结果可分享（用户分享诊断报告到朋友圈），自带传播属性。每个成功分享即是一次免费获客。
诊断结果生成分享图片 邀请好友解锁更多诊断次数 目标：月活10000
P4
第四阶段 · 3-6个月
社群激活：互助圈与真实故事
有了一定用户量后，激活互助圈功能。主动邀请早期用户分享真实故事，平台运营团队（你自己）每天精选高质量经历帖，在外部平台同步发布（走心故事天然传播）。目标让用户产生"这里有人真的在帮我"的情感连接。
每天精选1个真实突破故事 微信公众号 + 小红书内容矩阵 目标：月活50000，留存率30%+
🎯
最重要的冷启动原则：一个真实帮助比一百次广告有效
当你在豆瓣失业小组帮了一个真实的陈哥，他会主动告诉他的朋友圈；当你帮小林找到了武汉的2000元就业补贴，他会截图发给大学同学。破局的增长不依赖算法，依赖"真的帮到了人"产生的口碑效应。这是你作为一个人、没有资源能做到的最真实的护城河。
12 — 商业模式设计

如何可持续经营而不伤害用户

破局的商业模式必须建立在"越帮助人越赚钱"而非"越收割越赚钱"的逻辑上。核心用户免费，收入来自从中受益最多的人和企业，而非最困难的人。

⭐
增值服务订阅（主要收入）

免费：每天3次AI诊断、基础政府资源查询、基础路径地图

破局Plus（约39元/月）：无限AI诊断、简历深度优化（5份/月）、政府申请材料辅助生成、专属路径顾问（AI增强版）

定价参考：低于任何培训课程，低于一顿外卖，不让穷人望而却步

🏛️
政府/公益合作（稳健收入）

与人社局、残联、妇联等政府机构合作，成为官方就业服务平台的数字化延伸，获得政府购买服务资金；与公益基金会合作（阿里公益、腾讯公益），获得公益资助覆盖运营成本；参与政府"互联网+就业服务"项目招标。

🏢
B端机构服务（规模化收入）

为劳务派遣公司、职业技能培训机构、大学就业指导中心提供定制化服务：批量处理学生诊断、本地化政策数据订阅、反骗黑名单API接入。每年按机构规模收取SaaS费用。

📢
合规信息推送（小额收入）

经过严格审核的职业技能培训机构、企业内推岗位（非广告，是经核实的真实信息）可以付费推送给匹配用户。规则透明：明确标注"推广"，定价与传播价值挂钩，严禁骗局机构入驻。

💳
任务市场手续费（未来收入）

任务市场开通担保支付后，每笔担保支付收取5%手续费（与闲鱼类似）。规模起来后这是可观的流水，但初期不是重点，先积累用户和信任。

🚫
永远不做什么（商业底线）

永远不向最困难的用户（认定为"就业困难人员"的）收费；不出售用户个人数据；不接受骗局机构付费推广；不制造焦虑来销售课程；不用大量广告打扰用户体验；平台盈利前先保障核心功能的公益性。

最好的商业模式是：帮助最多的人，自然收获足够的回报。破局的目标不是成为独角兽，而是成为中国最值得信任的普通人帮扶平台——信任本身就是最大的商业价值。

开发注意事项：作为独立程序员的行动清单

  1. 先完成后完美 功能上线后才有真实用户反馈。宁可功能简陋但可用，也不要在本地开发完美但未验证的功能。"政府资源"第一版用Excel手动维护JSON也可以。
  2. Prompt工程是你的核心竞争力 在你不能自训练模型的情况下，谁的Prompt做得好，谁的产品体验就好。把时间投入在测试和优化Prompt上，和真实用户一起迭代，而不是在框架选型上反复纠结。
  3. 数据是你的壁垒 政府资源数据库、反骗案例库、真实路径成功案例——这些数据是你花时间积累的，是技术巨头难以快速复制的。从第一天起就建立数据意识，每个用户行为都是有价值的信号。
  4. 用微信生态降低获客成本 微信小程序 + 公众号 + 视频号三件套，是你在没有资金投放情况下触达最多目标用户的路径。内容营销（真实故事、数据解读、补贴信息）是你的增长引擎。
  5. 务必完成ICP备案和相关资质再上线 没有备案的小程序随时可能被下架。人力资源服务许可证是否需要取决于你是否"介绍就业"，建议上线前咨询律师明确边界。
  6. 定期做用户访谈，不少于每月2次 和真实的失业者、宝妈、中年转型者视频通话（30分钟），比看10份数据报告更有价值。他们的真实语言、真实困惑和真实期待，是你最好的产品文档。
