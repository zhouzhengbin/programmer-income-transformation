面向幼儿园小朋友的互动学习网站。**21 个游戏**，覆盖语文、数学、英语、常识四大领域。

## 怎么打开

双击 index.html 即可。想在手机上玩（触屏手感最好），右键运行 start.ps1，终端会显示手机访问地址。

## 五种互动方式

不只是拖拽。每个游戏都用了不同的交互，保持新鲜感：

- **拖拽** —— 拼音、数数、字母、颜色、影子、拼图
- **点击** —— 连线、选择题、单词卡、古诗
- **涂色** —— Canvas 区域填色，点哪涂哪
- **翻牌** —— 3D 翻转动画，记忆配对
- **限时挑战** —— 泡泡从下往上飘，点破正确答案

## 动态背景

用 Canvas 粒子系统做的三层视差背景：

- **云朵层** —— 3 朵白云缓慢横移，速度各不相同（更节制）
- **漂浮层** —— 星星、花瓣、蝴蝶（11 个漂浮元素，更克制）、叶子缓缓上升，左右摇摆并旋转
- **草浪层** —— 底部两重绿色波浪正弦起伏

设计上刻意做得**节制**：透明度低、速度慢，孩子看久了不累，但每次抬头都有新东西在动。
页面切到后台会自动暂停省电。

## 拼音发音（重点修复）

**问题**：中文语音引擎拿到孤立的字母 m，会按英文字母名读成 em。

**解法**：汉字锚定法。给每个拼音配一个同音汉字，让引擎读汉字：

```
b -> 玻    p -> 坡    m -> 摸    f -> 佛
h -> 喝    y -> 衣    w -> 乌    a -> 啊
```

实测 23 个声母、24 个韵母全部以中文朗读，零英文读法。
带声调的完整音节（ma、yu、hua）直接交给中文引擎，读音准确。

## 为小朋友做的设计

**答错不批评。** 只有轻微晃动和柔和提示音，说「再试试」。不扣分。

**每个动作都有回应。** 拿起卡片有轻响，答对是上行音阶，通关有和弦加彩带。
所有音效由 Web Audio 现场合成，零音频文件，永远不会加载失败。

**会说话。** 拖拼音念拼音，拖英文单词读英文，中英文自动切换。中文优先选童声 Yaoyao，其次 Huihui。

**手指点得准。** 所有按钮高度 >= 42px，主要按钮 >= 46px。

**眼睛不累。** 天空蓝到暖黄渐变，正文对比度 11.4:1（标准要求 4.5:1）。

**星星会留住。** 攒的星星存 localStorage，关掉再开还在。

**成就系统。** 5 个徽章：第一步、小星星、亮晶晶、百星达人、全能王。

## 想加内容？

所有题库集中在 js/data.js。想加一个拼音词，往 pinyinWords 数组里加一行：

```
py: 'bà'  word: '爸'  pic: '👨'  ini: 'b'  tone: 4
```

想加古诗，往 poems 数组里加：

```
title: '村居'  author: '高鼎'  emoji: '🪁'
lines: ['草长莺飞二月天，','拂堤杨柳醉春烟。','儿童散学归来早，','忙趁东风放纸鸢。']
```

保存刷新即生效。加单词、加形状、加算式都是同样方式。

## 更新记录（本次修复）

### 🐞 修复的问题

1. **影子配对看不到影子**：原来用 `filter: brightness(0) opacity(.28)` 让 emoji 变灰，
   结果在浅色卡片上几乎不可见。改为 `brightness(0) saturate(0)` + 透明度 0.92 的
   **纯黑剪影**，在浅蓝卡片上对比度达 **12.2:1**（远超 WCAG 4.5:1 标准）。

2. **拼图只能看到一张图、逻辑不对**：原来每个碎片都用同一个 emoji 通过 background-position
   位移，碎片几乎一样。改为 **Canvas 绘制完整场景后真实切片**——每片独立绘制自己那一格，
   9 片互不相同（已验证 9/9 唯一），拼接后还原完整画面。

3. **儿歌只是“读”不是“唱”**：新增 5 首真实儿歌音频（`assets/songs/*.mp3`），
   用 ffmpeg 合成**伴奏旋律**（正弦+泛音，带包络和回声）叠加 TTS 人声，
   整体响度归一化到 -16 LUFS。点歌词即播放整首演唱，进度条随播放走动。

4. **古诗标题不朗读**：现在进入自动朗读「诗名·作者」，标题可点击重听，
   连读模式先读标题再逐句读，并显示准确朝代（唐/宋/清）。

### ✨ 额外完善

- 古诗从 **8 首扩充到 16 首**（新增相思、寻隐者不遇、村居、小池、咏柳、赠汪伦、鹿柴、绝句）
- 古诗朝代标注修正（村居=清，小池=宋，其余=唐）
