# 🌈 快乐学习乐园

面向幼儿园小朋友（人教版语文 / 数学 / 英语启蒙）的互动游戏网站。
打开就能玩，不需要联网，不需要安装任何东西。

---

## 怎么打开

**最简单的办法**：双击 `index.html`，浏览器立刻打开。

**想在手机上玩**（推荐，触屏拖拽手感最好）：
右键 `start.ps1` → 用 PowerShell 运行。
终端会显示两个网址，手机连同一个 WiFi 后访问「手机访问」那个即可。

## 为小朋友做的设计

**答错不扣分、不批评。** 只有轻轻晃一下和一声柔和的提示音，
说「再试试」。孩子的信心比正确率重要。

**每个动作都有声音回应。** 拿起卡片有轻响，答对有上行音阶，
全部通关有欢快的和弦加彩带。声音都是用浏览器现场合成的，
不依赖任何音频文件，所以永远不会加载失败。

**会说话的老师。** 拖拼音会念拼音，拖英文单词会读英文，
用的是系统自带的语音，中英文自动切换。

**手指够得着。** 所有按钮高度都不小于 44 像素，
这是儿童手指点击的舒适尺寸。手机上也不会点错。

**眼睛不累。** 背景是天空蓝到暖黄的柔和渐变，
正文对比度 11.4:1，远超无障碍标准的 4.5:1。

**星星会记住。** 攒到的星星存在浏览器里，关掉再打开还在。

## 操作提示

- 右上角 🔊 按钮可以关掉声音（上课时有用）
- 顶部导航随时切换三个乐园
- 「← 回乐园大厅」按钮回到首页
- 汉字描红有「重新描」和「换一个字」两个按钮

---

## 技术说明

- 纯前端，零依赖，零构建步骤
- 单页应用，hash 式视图切换
- 拖拽同时支持鼠标和触摸（Pointer Events）
- 音效使用 Web Audio API 实时合成
- 语音使用浏览器 SpeechSynthesis

## 想加内容？很简单

每个游戏文件顶部的 `DATA` 或 `ROUNDS` 数组就是题库。
比如想在「拼音找朋友」里加一个「b — 爸」：

```js
{ pic:'👨', word:'爸', py:'bà', ini:'b' }
```

保存刷新就生效。加单词、加颜色、加算式都是同样的方式。
