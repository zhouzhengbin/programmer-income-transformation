私有内容基础设施：
你自己的"广播电台"

这是整个系统的核心。拥有自己的服务器、域名和内容管理系统，任何平台都无法封你、限制你、删除你的内容。

你将建立什么：一台属于你的服务器（在德国，受欧盟法律保护），上面运行你的网站（Ghost CMS），自动生成RSS订阅源，自动向订阅者发送邮件。这就是你的"传播总部"，所有其他平台都从这里获取内容。
01
购买域名（你的专属地址）
在 Namecheap 注册你的域名，约$8.88/年
+
💡
什么是域名？就像你家的门牌号，比如 yourname.com。你需要买一个，才能让别人找到你的网站。推荐选 .com 后缀，国际通用。
  1. ①
    打开浏览器，访问 https://www.namecheap.com（需要梯子）
  2. ②
    点击右上角 Sign Up，填写邮箱和密码，完成注册并验证邮箱
  3. ③
    在首页搜索框输入你想要的域名（例如 yourname.com 或 mybrand.com）
  4. ④
    如果显示 Available（绿色），点击购物车图标加入购物车
  5. ⑤
    点击右上角购物车 → View Cart → 关闭不需要的附加服务（WhoisGuard默认免费可以留着）
  6. ⑥
    点击 Confirm Order，选择信用卡支付（或PayPal），完成付款
  7. ⑦
    付款完成后，进入 Dashboard → Domain List，看到你的域名即成功
✅
域名取名建议：简短、好记、最好是你的名字或品牌名。避免用数字和连字符。比如 liwei.com、bestcontent.com 之类。
✅ 完成标志：你在Namecheap的Dashboard里看到你的域名，状态显示 Active。
02
配置 Cloudflare（免费CDN+DNS+防护）
把域名托管到Cloudflare，获得免费全球加速和防护
+
💡
什么是Cloudflare？全球最大CDN服务商，免费提供全球加速、防DDoS攻击、DNS管理。把你的域名放到Cloudflare，访问速度更快，也更安全。
  1. ①
    访问 https://www.cloudflare.com，点击 Sign Up 注册账号（用邮箱即可）
  2. ②
    登录后点击 Add a Site（添加网站），输入你刚购买的域名，点击 Add Site
  3. ③
    选择免费计划（Free Plan），点击 Continue
  4. ④
    Cloudflare会扫描你现有的DNS记录，直接点击 Continue
  5. ⑤
    页面会显示两个 Nameserver（域名服务器），类似：anna.ns.cloudflare.com 和 bob.ns.cloudflare.com，复制这两个地址
  6. ⑥
    回到 Namecheap → Domain List → 点击你的域名 → 找到 Nameservers → 选择 Custom DNS
  7. ⑦
    把Cloudflare给你的两个Nameserver地址粘贴进去，点击保存（绿色对勾图标）
  8. ⑧
    回到Cloudflare，点击 Done, check nameservers，等待5-30分钟生效
  9. ⑨
    生效后Cloudflare会发邮件通知你，此时你的域名状态变为 Active
✅ 完成标志：Cloudflare控制台中你的域名状态显示绿色 Active。

04
连接服务器（第一次登录）
用SSH工具连接到你的服务器，开始安装软件
+
💡
SSH是什么？就是远程控制服务器的工具，就像用遥控器控制你在德国的那台电脑。你在自己的电脑上打命令，服务器执行。
Windows 用户：
  1. ①
    下载安装 https://termius.com（免费版够用），或直接用Windows自带的 PowerShell
  2. ②
    打开PowerShell，输入：ssh root@你的服务器IP，按回车
  3. ③
    提示 "Are you sure you want to continue connecting"，输入 yes 回车
  4. ④
    输入Hetzner发给你邮件里的密码，回车（输入时看不到字符，这是正常的）
  5. ⑤
    成功后会看到提示符变成 root@localhost:~#，说明你已登录服务器
Mac 用户：
  1. ①
    打开 终端（Terminal），在应用程序→实用工具中找到
  2. ②
    输入命令：ssh root@你的服务器IP，后续步骤和Windows一样
// 登录后第一件事，更新系统
apt update && apt upgrade -y
✅
看到大量滚动文字是正常的，等待进度结束，出现 root@ 提示符即完成更新。这个过程需要2-5分钟。

部署 Ghost CMS（你的内容管理系统）
Ghost是专业博客平台，自动生成RSS，内置邮件订阅
+
💡
Ghost是什么？比WordPress更现代的内容发布平台，专为内容创作者设计。发布文章，自动生成RSS订阅源，自动向订阅者发邮件。
// 第1步：创建Ghost目录
mkdir -p /opt/ghost && cd /opt/ghost
// 第2步：创建配置文件（复制以下全部内容粘贴执行）
cat > docker-compose.yml << 'EOF' version: '3' services: ghost: image: ghost:latest restart: always ports: - "2368:2368" environment: url: https://你的域名.com database__client: mysql database__connection__host: db database__connection__user: ghost database__connection__password: ghostpassword123 database__connection__database: ghost volumes: - ghost-data:/var/lib/ghost/content depends_on: - db db: image: mysql:8.0 restart: always environment: MYSQL_ROOT_PASSWORD: rootpassword123 MYSQL_DATABASE: ghost MYSQL_USER: ghost MYSQL_PASSWORD: ghostpassword123 volumes: - db-data:/var/lib/mysql volumes: ghost-data: db-data: EOF
⚠️
重要：把上面 你的域名.com 替换成你真实的域名。密码可以改成更复杂的字符串，记在Notion里。
// 第3步：启动Ghost
docker compose up -d
// 第4步：等待1分钟后检查是否正常运行
docker compose ps
  1. ⑤
    回到Cloudflare控制台 → 你的域名 → DNS → Add Record
  2. ⑥
    类型选 A，Name填 @，IPv4 address填你的服务器IP，Proxy status开启（橙色云朵），点保存
  3. ⑦
    再添加一条：类型 A，Name填 www，IPv4填同一IP，保存
  4. ⑧
    等待5-10分钟DNS生效后，访问 http://你的域名.com:2368，看到Ghost欢迎页即成功
  5. ⑨
    访问 http://你的域名.com:2368/ghost 进行初始化设置：填网站名、管理员邮箱、密码
💡
配置HTTPS（安全锁标志）：Cloudflare已经自动帮你处理HTTPS，在Cloudflare → SSL/TLS → 选择 Full 模式即可。
✅ 完成标志：能访问你的域名看到Ghost网站，能进入 /ghost 管理后台，RSS地址 yourdomain.com/rss 能正常打开。

08
配置 Amazon SES（每月62000封免费邮件）
亚马逊邮件发送服务，送达率最高，每月免费额度超足
+
  1. ①
    访问 https://aws.amazon.com，点击 Create an AWS Account，完成注册（需要信用卡验证，但不会扣费）
  2. ②
    登录AWS控制台，在顶部搜索框输入 SES，点击进入 Amazon Simple Email Service
  3. ③
    左侧菜单点击 Verified identities → Create identity
  4. ④
    选择 Domain，输入你的域名，点击 Create identity
  5. ⑤
    AWS会给你一些DNS记录，把这些记录添加到Cloudflare的DNS里（CNAME和TXT记录）
  6. ⑥
    等待几分钟后，域名状态变为 Verified
  7. ⑦
    左侧点击 SMTP Settings → Create SMTP credentials，生成用户名和密码
  8. ⑧

  9. ⑨
    回到Listmonk → Settings → SMTP填写：
    • Host: email-smtp.us-east-1.amazonaws.com（根据你的区域不同）
    • Port: 587
    • Username: 刚才生成的SMTP用户名
    • Password: 刚才生成的SMTP密码
  10. ⑩
    点击 Save & Test，发送测试邮件验证配置正确
⚠️
沙盒限制：新注册的AWS SES账号在"沙盒模式"，只能给已验证的邮件地址发邮件。需要提交申请解除限制（在SES页面找到 "Request production access"），说明你是做内容传播，通常1-2天内批准。
✅ 完成标志：测试邮件发送成功，收件箱收到测试邮件。
CHAPTER 02 全免费 被动获客

RSS 全球聚合网络：
让全世界主动来抓你的内容

RSS是互联网最古老的内容分发协议。全球数千个聚合器主动抓取RSS内容，你只需提交一次，内容自动被全球分发，永久有效。

你的RSS地址是：https://你的域名.com/rss
Ghost自动生成。每次你发布新文章，RSS会自动更新。所有聚合器看到更新后，会主动同步你的内容。这是完全被动的流量来源，设置一次，终生有效。

配置 WebSub（发布即实时推送，无需等待抓取）
W3C标准协议，新内容0秒同步至所有订阅聚合器
+
💡
WebSub原理：普通RSS聚合器每隔1小时来"轮询"一次你的RSS看有没有新内容。WebSub让你发布新内容时主动"推送"通知给聚合器，实时同步。
  1. ①
    Ghost已内置WebSub支持。访问 Ghost管理后台 → Settings → General
  2. ②
    找到 Subscription Settings，Hub URL填入：https://pubsubhubbub.appspot.com/
  3. ③
