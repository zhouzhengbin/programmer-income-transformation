24. 认知升级：什么是多智能体 (Multi-Agent)？

小白眼中的自动化：写一段代码，按顺序执行 A -> B -> C。如果 B 报错了，整个程序崩溃（比如 Facebook 突然弹出一个验证码，RPA 就死机了）。

架构师眼中的自动化 (Agentic Workflow)： 建立一个“AI 老板”，手下管着“爬虫专员”、“翻译专员”、“销售专员”。如果“爬虫专员”遇到验证码，“AI 老板”会自动调用“打码接口”解决，或者命令机器人休眠 10 分钟后重试，并给你发一条钉钉消息。它具备自主决策和纠错的能力。

25. 万物互联：Webhook (网络钩子) 的魔法

怎么让“影刀 RPA（桌面软件）”和“Coze（云端 AI）”对话？答案是：Webhook。你可以把它理解为一条隐秘的地下电报线。只要有人往这个地址发送一串密码电报，远端的机器就会瞬间启动。

实操场景： 影刀抓到了一个老外的求购贴。影刀需要把这段话立刻“扔”给 Coze，让 Coze 写好外语销售信，再把写好的信“扔”回给影刀，最后由影刀发送到 WhatsApp。
1 配置 Coze 工作流的 Webhook 触发器
  1. 在 Coze (扣子) 中打开你的工作流，点击右上角的 “发布 (Publish)”。
  2. 在发布选项中，勾选 “Webhook”。系统会生成一个长长的 URL 地址和一个 Bearer Token (鉴权密码)。
  3. 复制它们，把它们当成你保险箱的钥匙，绝对不要泄露给别人。
2 在 RPA 中发送 HTTP POST 请求

在影刀中，拖入 “发送 HTTP 请求” 指令。按照以下极其严格的格式填写：

HTTP POST CONFIGURATION
// 1. 请求 URL (填入 Coze 给你的 Webhook 地址) URL: https://api.coze.cn/v1/workflow/run // 2. 请求头 (Headers) - 必须表明身份和数据格式 Authorization: Bearer pat_XXXXX你的TokenXXXXX Content-Type: application/json // 3. 请求体 (Body) - 发送给 AI 的数据包 (JSON 格式) { "workflow_id": "7358294710382XXXX", "parameters": { "raw_lead_text": "Hola, ocupo tubo de pvc de 4 pulgadas.", "customer_phone": "5212345678" } }

影刀执行这一步后，Coze 的云端服务器会瞬间被激活，处理完毕后，会将写好的推销信通过一段新的 JSON 数据返回给影刀。这就是大闭环！

26. 赛博监工：Cron 定时任务与异常捕获

一个真正的全自动系统，不需要你每天早上点击“运行”按钮。它必须随着目标国家的日出日落，自己醒来、自己工作、自己休眠。

配置“全球时差作息表” (Cron Job)

做南美生意，老外活跃的时间是北京时间的深夜。让机器人在半夜跑起来：

  • 在影刀控制台中，找到“定时任务 (触发器)”。
  • 设置 Cron 表达式：比如 0 0 10 * * ? (表示当地时间每天上午 10 点触发)。
  • 让机器人在老外刚上班喝咖啡的时候，准时把开发信发到他的手机上。
异常捕获与“自愈”机制 (Self-Healing)

系统运行的第 3 天，Facebook 的网络突然卡了 10 秒钟，按钮没加载出来。如果没有“自愈机制”，程序直接报错停止，你一天的外汇就泡汤了。

高级架构师的 Try-Catch 逻辑：
RPA SELF-HEALING ALGORITHM
// 建立错误重试机制循环 变量 Retry_Count = 0 While (Retry_Count < 3): Try 尝试执行: 点击网页上的 "Send Message" 按钮 发送 HTTP 请求给 Coze Break (如果成功，跳出循环，继续下一个客户) Catch 如果捕获到错误 (比如网络超时、元素找不到): Retry_Count = Retry_Count + 1 // 自愈动作：刷新当前页面，强制休眠 15 秒后重试 刷新当前网页() 休眠(15000) If (Retry_Count == 3): // 如果连续失败 3 次，说明平台风控或页面结构大改 通过企业微信 API，发送警报给老板(你): "🚨 警告：Facebook 抓取模块崩溃，重试3次失败。已暂停工作流，请人工介入检查！"
