# 二年级数学（上下册）动画课堂

人教版小学二年级数学上下册，17 个知识点的可视化动画教学 H5。
纯前端、零依赖、双击即开。

## 打开

双击 `index.html`。

## 上传

用 `index-standalone.html`（单文件版），改名为 index.html 上传。

## 课程（17 课）

**上册 9 课**：100以内加法、进位加法、退位减法、角的初步认识、
表内乘法、观察物体、长度单位、认识时间、数学广角·搭配

**下册 8 课**：数据收集整理、除法的初步认识、轴对称图形、
平移、旋转、有余数的除法、万以内数的认识、克与千克

## 功能

开始/暂停 · 下一步 · 换一题 · 练一题 · 闯关（连答5题）
语音播报 + 音效，可开关调音量。进度自动保存。全设备自适应。

## 技术

Canvas 2D 手绘动画，WebAudio 合成音效，浏览器 TTS 语音。
无图片、无音频文件、无外部依赖。

## 已知限制

- 语音是系统 TTS，不是真人童声录制
- 拼音是页面文案的固定标注，非通用转换
