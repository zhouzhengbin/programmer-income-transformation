# 二年级数学（上下册）动画课堂 · 部署说明

## 一、项目说明

纯前端 H5 教学页面，人教版小学二年级数学上下册 **17 个知识点**。
所有动画用 Canvas 2D 手绘，零依赖、零图片、零音频文件。

## 二、本地打开

双击 `index.html`，用 Chrome / Edge 打开。

## 三、上传到网站（推荐单文件版）

用 `index-standalone.html` 一个文件就够了，CSS 和 JS 已全部内联。

1. 改名为 `index.html`
2. 上传到网站目录
3. 完成

**免费托管**：GitHub Pages、Netlify、Vercel、Gitee Pages（国内推荐）
**云存储**：阿里云 OSS、腾讯云 COS 静态网站

注意：必须 HTTPS，语音功能才正常。

## 四、课程内容

### 上册 9 课

| 单元 | 课程 | 动画演示 |
|---|---|---|
| 一 | 100以内加法 | 数位表格，数字飞入格位 |
| 二 | 进位加法 | 小棒满十自动捆扎 |
| 二 | 退位减法 | 整捆散开，借一当十 |
| 三 | 角的初步认识 | 两条边旋转生成角 |
| 四 | 表内乘法 | 圆点排成行列方阵 |
| 五 | 观察物体 | 立体方块 + 前/侧/上三视角 |
| 六 | 长度单位 | 尺子刻度 + 滑动测量 |
| 七 | 认识时间 | 真实钟面，分针转一圈 |
| 八 | 数学广角·搭配 | 上衣裤子连线 |

## 五、功能

- **开始/暂停** —— 播放动画，语音+文字同步讲解每一步
- **下一步** —— 单步推进，适合家长陪讲
- **换一题** —— 随机换数据重新演示（17 课全支持）
- **练一题** —— 单题练习，4 选 1
- **闯关** —— 连答 5 题，实时进度，全对触发奖励动画
- 语音播报 + 童趣音效，可开关可调音量
- 学习进度存 localStorage
- 全设备自适应

## 六、注意事项

- 语音用浏览器内置 TTS，无需音频文件
- 首次打开需点击屏幕才能出声（浏览器限制）
- 手机上建议横屏
