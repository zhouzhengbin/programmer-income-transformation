在使用机器人之前，你必须知道目标客户聚集在哪里。我们不抓普通的消费者（C端），我们要抓的是小B端（小批发商、实体店老板、包工头）。

目标平台 数据特征与价值 搜索指令演示 (以寻找南美五金商为例)
Facebook Groups (群组) 极高。全球小商人最爱在群组里发帖求购。里面充满了直接留 WhatsApp 号码的“直客”。 使用目标国语言搜索群组："importadores de ferreteria" (五金进口商 - 西班牙语)
Google Maps (谷歌地图) 极稳定。抓取当地实体店面的公开邮箱、官网和电话。适合长线开发。 在地图中定位到墨西哥城，搜索："Ferretería" (五金店)

06. 手把手构建：影刀RPA“脸书自动抽水机”

接下来是核心的动手工序。请打开你在Part 2安装好的【影刀RPA】，创建一个新的【PC网页自动化】应用，命名为“FB五金客源挖掘机”。

步骤 1：环境接管与页面初始化

不要让影刀去打开普通的Chrome，我们要让它接管我们在Part 2中配置好的“指纹浏览器（AdsPower）”。

  1. 在指令面板搜索：“接管已打开的浏览器”。
  2. 通过窗口标题匹配你的 AdsPower 浏览器窗口。
  3. 加入指令：“打开网页”，填入你提前找好的Facebook群组链接（例如：https://www.facebook.com/groups/xxxxxx）。
  4. 极其重要的一步： 加入指令：“等待网页加载完成”，并设置一个随机延迟（如等待 3 到 7 秒）。老外的网络通常较慢，不等待直接抓取会导致机器人崩溃。
步骤 2：破解瀑布流与自动向下滚动

Facebook是“瀑布流”网页，你不往下滚，新的帖子就不会加载出来。我们需要写一个循环逻辑：

For 循环 (变量 i 从 1 到 50): // 模拟人类浏览动作，防止被Facebook判定为机器人 鼠标滚动 (向下滚动 800 像素) 随机延时 (产生一个 2秒 到 5秒 的随机数并等待) // 展开长帖子，寻找隐藏的电话号码 If 判断 (网页中是否存在文本 "See more" / "查看更多"): 点击元素 ("See more" 按钮) End For

这段逻辑会让机器人在前台像一个真实用户一样，慢条斯理地往下刷50次屏幕，把所有的隐藏帖子全部展开，露出里面的邮箱和WhatsApp号码。

步骤 3：数据捕获与结构化清洗 (XPath魔法)

页面展开后，我们需要把有用的信息精准地摘取下来。

在影刀中，使用“数据抓取 (批量)”指令。按照提示，点击页面上第一个帖子的“发帖人名字”，再点击第二个帖子的“发帖人名字”，影刀会自动生成类似 //div[@class='x1y1aw1k']/span/a 的 XPath 代码，瞬间选中所有发帖人。

你需要建立一个包含以下4列的数据表（Data Table）：
  • 列A：发帖人名称 (用于开发信称呼)
  • 列B：帖子主页链接 (用于备用联系)
  • 列C：帖子正文完整内容 (极其重要！下节课我们将把它喂给AI进行分析)
  • 列D：发布时间 (剔除1年前的无效老帖)
步骤 4：数据落盘与异常捕捉 (Try-Catch)

网络是不稳定的。如果抓到一半断网了，或者Facebook突然弹出一个验证码，你的机器人直接崩溃报错，前面抓的数据就全丢了。

引入 “Try-Catch (异常处理)” 机制：

Try 尝试执行: 执行上面定义的 [滚动页面] 和 [批量抓取数据] Catch 如果发生任何报错: 保存数据表至Excel (路径: "C:\Desktop\LeadData_ErrorBackup.xlsx") 发送企业微信/钉钉通知 ("老板，抓取中断，可能遇到验证码，已自动备份数据！") 终止流程 Finally 无论是否报错最后都执行: 保存数据表至Excel (路径: "C:\Desktop\LeadData_Final.xlsx") 关闭当前网页窗口

07. 赛博对抗：如何让平台觉得你“是一个人”？

很多小白的机器人活不过一天，因为他们把操作速度调到了最快。 机器瞬间点击100次，Facebook的风控AI 0.1秒就能判定你是爬虫，直接永久封号。做自动化的核心哲学是：“要慢，要蠢，要像人。”
小白做法 (极易被封) 专业架构师做法 (高存活率)
固定等待时间：每次翻页死板地等待 3000毫秒。 随机噪音注入： 每次等待时间设定为 Random(2145, 5320) 毫秒，毫无规律。
鼠标瞬间移动：光标从屏幕左上角瞬间瞬移到右下角点击。 模拟鼠标轨迹： 开启影刀的“拟人化鼠标移动”，鼠标会划出一条带有弧度、甚至会微微抖动的贝塞尔曲线。
7x24小时不间断抓取。 模拟作息： 设置条件：只有在目标国度（如墨西哥）的当地时间上午9点到下午6点之间运行，周末自动暂停。
